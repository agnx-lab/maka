# maka-jev-native

[English](README.md)

注册 Jev 服务，将公开契约连接到评估引擎和设置存储。`provide` 向 Host 添加工厂。产品绑定与调用准入决定谁可以访问配置的端点。

凭据资源按原端点和版本意图完整读取。完整评估结果仍区分已确认结果与远端 POST 的不确定回执；所有者关闭仍等待原调用范围和 HTTP 清理。
